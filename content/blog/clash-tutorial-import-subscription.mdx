# 机场订阅链接怎么导入 Clash？详细图文教程

## 简短摘要
Clash 是目前桌面端最流行的科学上网客户端之一。通常只需在机场官网点击“一键导入 Clash”或手动复制订阅地址到 Clash 的 Profiles 面板中进行下载即可使用。

## 准备工作
目前原版 Clash For Windows 已经停止维护，推荐下载基于全新内核的 **Clash Verge Rev** 或 **Mihomo** 客户端。

## 实际操作步骤

### 第1步：获取订阅链接
登录您购买的 [机场推荐品牌](/airports) 官网控制面板，找到“一键订阅”区域，点击“复制 Clash 订阅链接”。

### 第2步：在客户端中添加配置
1. 打开 Clash 客户端。
2. 找到左侧的 **配置 (Profiles) / 订阅 (Subscriptions)** 面板。
3. 在顶部输入框粘贴刚才复制的链接，点击 **导入 (Import / Download)**。

### 第3步：选择代理节点
1. 导入成功后，在配置列表中选中刚下载好的配置文件。
2. 点击左侧的 **代理 (Proxies)**。
3. 展开下拉菜单，选择您需要的国家节点（如香港、日本）。

### 第4步：开启系统代理
回到 **设置 (Settings) / 主页 (Home)**，打开 **System Proxy (系统代理)** 开关，您的电脑即可科学上网。

## 常见问题解决
**导入订阅失败怎么办？**
- 检查复制的链接是否完整。
- 部分旧版 Clash 不支持某些新型协议，请务必升级到最新的 Clash Verge Rev。
- 确认机场官网给出的订阅转换是否临时出现故障，可尝试重新复制。
