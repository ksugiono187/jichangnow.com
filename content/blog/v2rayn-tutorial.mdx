# v2rayN机场怎么使用？Windows端订阅配置指南

## 简短摘要
v2rayN 是一款轻量、老牌且免费的 Windows 科学上网客户端。通过“订阅”菜单中的“订阅设置”可以非常方便地导入各类机场节点。

## 第1步：下载与安装
请前往 GitHub 下载带有 Core（内核）的完整 v2rayN 压缩包（如 `v2rayN-Core.zip`）。**必须解压到一个单独的文件夹中**后，再双击运行 `v2rayN.exe`。

## 第2步：导入订阅链接
1. 打开 v2rayN 界面。
2. 登录您的 [机场管理面板](/airports)，复制“通用 V2Ray 订阅链接”。
3. 在 v2rayN 顶部菜单栏点击 **订阅 -> 订阅设置**。
4. 点击“添加”，在“地址（url）”处粘贴链接，并在“备注”处填入机场名字，点击“确定”。
5. 返回主界面，点击菜单栏 **订阅 -> 更新订阅**，下方列表即会出现节点。

## 第3步：启动系统代理
1. 在节点列表中单击选中一个国家节点，按回车键使其变为设为活动节点（前面会打钩）。
2. 在右下角系统托盘找到 v2rayN 的小图标，**右键点击**。
3. 找到 **系统代理**，选择 **自动配置系统代理**（此时图标会变成红色）。

## 故障排查
遇到“真连接测试超时”：
- 请尝试更新订阅。
- 确认您的套餐没有过期。
- 更换一个其他节点再测。您可以参考本站的 [机场横向对比](/compare) 看看其他机场的稳定性表现。
